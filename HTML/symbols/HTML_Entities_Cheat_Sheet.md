# HTML Special Characters & Entities Cheat Sheet

> Format: **Character → Meaning → HTML Entity / Numeric Code**

## Basic Symbols

```text
    --> SPACE              --> &nbsp;
!   --> EXCLAMATION        --> &#33;
"   --> DOUBLE QUOTE       --> &quot;
#   --> HASH               --> &#35;
$   --> DOLLAR             --> &dollar;
%   --> PERCENT            --> &#37;
&   --> AMPERSAND          --> &amp;
'   --> APOSTROPHE         --> &apos;
(   --> LEFT PARENTHESIS   --> &#40;
)   --> RIGHT PARENTHESIS  --> &#41;
*   --> ASTERISK           --> &ast;
+   --> PLUS               --> &plus;
,   --> COMMA              --> &#44;
-   --> HYPHEN             --> &#45;
.   --> PERIOD             --> &#46;
/   --> SLASH              --> &#47;

:   --> COLON              --> &#58;
;   --> SEMICOLON          --> &#59;
<   --> LESS THAN          --> &lt;
=   --> EQUAL              --> &#61;
>   --> GREATER THAN       --> &gt;
?   --> QUESTION MARK      --> &#63;
@   --> AT                 --> &#64;

[   --> LEFT BRACKET       --> &#91;
\   --> BACKSLASH          --> &#92;
]   --> RIGHT BRACKET      --> &#93;
^   --> CARET              --> &#94;
_   --> UNDERSCORE         --> &#95;
`   --> BACKTICK           --> &#96;

{   --> LEFT BRACE         --> &#123;
|   --> VERTICAL BAR       --> &#124;
}   --> RIGHT BRACE        --> &#125;
~   --> TILDE              --> &#126;
```

## Common HTML Entities

```text
    --> SPACE              --> &nbsp;
•   --> BULLET             --> &bull;
·   --> MIDDLE DOT         --> &middot;
…   --> ELLIPSIS           --> &hellip;
©   --> COPYRIGHT          --> &copy;
®   --> REGISTERED         --> &reg;
™   --> TRADEMARK          --> &trade;
°   --> DEGREE             --> &deg;
±   --> PLUS/MINUS         --> &plusmn;
×   --> MULTIPLICATION     --> &times;
÷   --> DIVISION           --> &divide;
≤   --> LESS/EQUAL         --> &le;
≥   --> GREATER/EQUAL      --> &ge;
≠   --> NOT EQUAL          --> &ne;
≈   --> APPROXIMATELY      --> &asymp;
∞   --> INFINITY           --> &infin;
√   --> SQUARE ROOT        --> &radic;

```

## Arrows

```text
←   --> LEFT ARROW          --> &larr;
→   --> RIGHT ARROW         --> &rarr;
↑   --> UP ARROW            --> &uarr;
↓   --> DOWN ARROW          --> &darr;
↔   --> LEFT-RIGHT ARROW    --> &harr;

⇐   --> LEFT DOUBLE ARROW   --> &lArr;
⇒   --> RIGHT DOUBLE ARROW  --> &rArr;
⇑   --> UP DOUBLE ARROW     --> &uArr;
⇓   --> DOWN DOUBLE ARROW   --> &dArr;
```

## Common HTML Escape Characters


## Examples

### Bullet List

```html
&bull; HTML
&bull; CSS
&bull; JavaScript
```

Output:

```text
• HTML
• CSS
• JavaScript
```

### Special Characters

```html
&lt;h1&gt;Hello&lt;/h1&gt;
```

Output:

```text
<h1>Hello</h1>
```

### Copyright

```html
&copy; 2026 Thejas B J
```

Output:

```text
© 2026 Thejas B J
```

### Rupee Symbol

```html
&#8377; 500
```

Output:

```text
₹ 500
```
