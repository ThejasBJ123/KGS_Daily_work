# 🐍 Full-Stack Python Daily Tasks & Practice

Welcome to the **Full-Stack Python Daily Tasks** repository! This repository tracks hands-on coding exercises, problem-solving challenges, and daily practice assignments covering core Python concepts, data structures, algorithms, and real-world implementations.

---

## 📌 Repository Structure

### 📁 Week 1
* **Numericals & Core Logic:**
  - `armstrong_palindrome_reverse.ipynb`: Logic for Armstrong numbers, Palindromes, and number reversal.
  - `even_odd_and_leapyear.ipynb`: Conditional logic, parity checks, and leap year calculations.
  - `factors_primes_gcd.ipynb`: Prime number testing, factors generation, and GCD computation.
  - `oops_concepts_and_ascii.ipynb`: Introduction to OOPs fundamentals and ASCII conversions.
  - `python_functions_and_scope.ipynb`: Function definitions, parameters, return values, and variable scopes.
* **Strings:**
  - `string_search_methods.ipynb`: Substring search, finding occurrences, and string matching techniques.
  - `string_slicing_and_indexing.ipynb`: Indexing patterns, forward & backward slicing tricks.
